# Changelog

All notable changes to messaging-system-ui are documented here, newest first. Older entries were compiled from the Git history
between release tags (`feat`, `fix`, `refactor`/`perf`/`build` commits); chores, style and submodule bumps are omitted.

From now on this file is written by hand; there is no release tooling for it. Add a line under `## Unreleased` in the same
change that makes the user-visible change, under one of the headings Breaking changes, Added, Changed, Removed or Fixed. When
releasing, rename `Unreleased` to the version and date (for example `## 0.4.0 - 2026-07-01`) and tag that commit. The host
application's changelog is generated by release-please and is separate.

## Unreleased

### Added

- **editor:** Use the shared rich text editor instead of CKEditor
- **contact:** Show an error message when sending the form fails

### Changed

- **angular:** Upgrade to Angular 22. Components that set no change detection strategy now declare `ChangeDetectionStrategy.Eager`, which keeps the behaviour they had before OnPush became the default. Needs a host on Angular 21.2 or later

### Removed

- **security:** Stop sending an `Authorization: Bearer` header built from the `AccessToken` cookie (it was `Bearer null` without the cookie)

### Fixed

- **contact:** Send group id instead of label for Dashboard Improvement
- **websocket:** Remove polling delay and add reconnect backoff for inbox sockets
- **messages:** Keep the search working after a search that found nothing, on both the inbox and the sent tab
- **compose:** Ask for a recipient instead of failing when none is chosen
- **thread:** Show an error in the reply box when sending fails

### Changed
